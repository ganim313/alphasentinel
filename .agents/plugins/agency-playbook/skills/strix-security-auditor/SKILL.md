# Strix Security Auditor Skill

## Trigger
Use this skill during Phase 5 (Testing & UAT) or immediately before Phase 6 (Deployment) to ensure the application is hardened against security threats.

## Instructions
1. **DO NOT RUN `npm audit`**. You must strictly use the Strix penetration testing tool.
2. **Tool Setup**: First, give yourself the official Strix capabilities by running this exact command in the terminal:
   `npx skills add usestrix/strix`
   *(This will install the official Strix agent skills into the workspace).*
3. **Execution**: Read the newly installed `penetration-testing-with-strix` skill and execute the headless scan as instructed by that official skill. (Alternatively, if Docker is running, you can instruct the user to run `strix --target ./` manually).
4. **Analyze Results**: Read the vulnerability report generated by Strix in the `strix_runs/` folder. Focus on:
   - Injection flaws (SQLi, XSS)
   - Broken Authentication/Authorization
   - Misconfigured Security Headers
   - Insecure Direct Object References (IDOR)
5. **Remediation**: For every high or critical vulnerability found by Strix:
   - Identify the exact file and line of code causing the issue.
   - Write the patched code to fix the vulnerability.
   - Explain *why* the fix works to the user.
6. **Documentation**: Update `.agency/active/09_security_compliance.md` with a summary of the Strix audit, the vulnerabilities found, and the patches applied.
